# 🎮 Diablo2Campagn

## 📥 Guide d'installation

### 1. Télécharger Diablo2Campagn


### 2. Télécharger D2LoD (obligatoire)

Diablo2Campagn utilise les données de D2LoD pour générer les informations des cartes de jeu.

Téléchargez l'archive ici :

**[⬇️ Télécharger D2LoD (1,8 Go)](https://drive.google.com/file/d/1KWmTJWS4GCGylAJEiicAYNXIjx5jZCDO/view?usp=drive_link)**

Une fois le téléchargement terminé :

1. Extrayez le contenu de `d2lod.zip`.
2. Placez le dossier `d2lod` dans le dossier `bin` de Diablo2Campagn.

Le dossier du jeu est celui qui contient `CampagneD2.exe`. Les fichiers de Lord of Destruction doivent être à côté de `d2-mapgen.exe` :

```text
Diablo2Campagn/
│
├── CampagneD2.exe
│
└── Campagn/
    └── bin/
        ├── d2-mapgen.exe
        ├── d2data.mpq
        ├── d2exp.mpq
        └── ...
```

`d2data.mpq` dans `Campagn\bin\d2lod`, ou directement dans `Campagn`, est aussi accepté.

**Attention :** ne mets pas ces fichiers dans le dossier de Diablo II: Resurrected.

Pour afficher la carte : lance D2R, entre en jeu avec un personnage, clique sur la fenêtre du jeu, puis lance `CampagneD2.exe` (il redemande les droits administrateur si besoin). L'overlay reste caché tant que D2R n'est pas la fenêtre active.


## ✅ Installation terminée !

Diablo2Campagn est maintenant prêt à être utilisé.

Bon jeu !
