# 🎮 Diablo2Campagn

## 📥 Guide d'installation

### 1. Télécharger Diablo2Campagn


### 2. Télécharger D2LoD (obligatoire)

Diablo2Campagn utilise les données de D2LoD pour générer les informations des cartes de jeu.

Téléchargez l'archive ici :

**[⬇️ Télécharger D2LoD (1,8 Go)](https://drive.google.com/file/d/1KWmTJWS4GCGylAJEiicAYNXIjx5jZCDO/view?usp=drive_link)**

Une fois le téléchargement terminé :

1. Extrayez le contenu de `d2lod.zip`.
2. Placez le dossier `d2lod` dans le dossier `bin` de Diablo2Campagn.

La structure doit être la suivante :

```text
Diablo2Campagn/
│
├── bin/
│   └── d2lod/
│       └── ...
│
└── ...
```

**Attention :** Le dossier `d2lod` doit impérativement se trouver dans `Diablo2Campagn/bin/d2lod`.

Ne l'installez pas dans le dossier de Diablo II: Resurrected.


## ✅ Installation terminée !

Diablo2Campagn est maintenant prêt à être utilisé.

Bon jeu !
